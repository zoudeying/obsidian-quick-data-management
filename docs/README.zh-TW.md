## ✨ 外掛功能

- 🚀 **極簡配置**：
    - 無需繁瑣設定，只需填入遠端服務設定即可開箱即用。
- 📗 **筆記即時管理**：
    - 自動監聽並處理倉庫內所有筆記的建立、更新與刪除操作。
- 🖼️ **附件全面支援**：
    - 即時處理圖片、影片、音訊等各類非設定檔案。
- ⚙️ **配置同步**：
    - 支援多台設備的配置管理與同步，告別手動複製配置檔案的煩惱。
- 🛂 **排除與規則**：
    - 提供路徑排除與自訂規則，打造專屬的資料處理策略。
- 🔄 **多端支援**：
    - 支援 Mac、Windows、Android、iOS 等平台。
- 📝 **筆記歷史**：
    - 提供筆記歷史功能，隨時檢視修改紀錄並支援版本恢復。
- 🛡️ **離線編輯保護**：
    - 對離線編輯提供增量比對與自動合併，保護筆記內容安全。
- 🔍 **版本檢測**：
    - 快速獲取外掛及服務端的版本狀態，便於平滑升級。
- ☁️ **附件雲預覽**：
    - 提供附件按需雲端預覽，節省本地儲存空間。
- 🗒️ **操作日誌**：
    - 詳細的操作與同步日誌，清晰追溯每一次操作紀錄。

## 🚀 快速開始

**第一步：安裝外掛**

* **BRAT 測試安裝（推薦）：** 開啟 Obsidian 設定 > 社群外掛 > 啟動 BRAT 外掛，新增 `zoudeying/obsidian-quick-data-management` 即可安裝並自動追蹤最新發佈。
* **手動下載：** 從 [GitHub 發佈頁](https://github.com/zoudeying/obsidian-quick-data-management/releases) 獲取 `main.js`, `styles.css`, `manifest.json`，放入倉庫的 `.obsidian/plugins/obsidian-quick-data-management` 目錄中。

**第二步：設定與使用**

1. 開啟 Obsidian 設定中的 **Quick Data Management**。
2. 填入您的遠端服務地址與授權權杖。
3. 連線成功後，即可開啟高效的資料管理與備份體驗。
