## ✨ 插件功能

- 🚀 **极简配置**：
    - 无需繁琐设置，只需填入远端服务配置即可开箱即用。
- 📗 **笔记实时管理**：
    - 自动监听并处理仓库内所有笔记的创建、更新与删除操作。
- 🖼️ **附件全面支持**：
    - 实时处理图片、视频、音频等各类非设置文件。
- ⚙️ **配置同步**：
    - 支持多台设备的配置管理与同步，告别手动拷贝配置文件的烦恼。
- 🛂 **排除与规则**：
    - 提供路径排除与自定义规则，定制专属的数据处理策略。
- 🔄 **多端支持**：
    - 支持 Mac、Windows、Android、iOS 等平台。
- 📝 **笔记历史**：
    - 提供笔记历史功能，随时查看修改记录并支持版本恢复。
- 🛡️ **离线编辑保护**：
    - 对离线编辑提供增量比对与自动合并，保护笔记内容安全。
- 🔍 **版本检测**：
    - 快速获取插件及服务端的版本状态，便于平滑升级。
- ☁️ **附件云预览**：
    - 提供附件按需云预览，节省本地存储空间。
- 🗒️ **操作日志**：
    - 详细的操作与同步日志，清晰追溯每一次操作记录。

## 🚀 快速开始

**第一步：安装插件**

* **BRAT 测试安装（推荐）：** 打开 Obsidian 设置 > 社区插件 > 启动 BRAT 插件，添加 `zoudeying/obsidian-quick-data-management` 即可安装并自动跟踪最新发布。
* **手动下载：** 从 [GitHub 发布页](https://github.com/zoudeying/obsidian-quick-data-management/releases) 获取 `main.js`, `styles.css`, `manifest.json`，放入仓库的 `.obsidian/plugins/obsidian-quick-data-management` 目录中。

**第二步：配置与使用**

1. 打开 Obsidian 设置中的 **Quick Data Management**。
2. 填入您的远端服务地址与授权令牌。
3. 连接成功后，即可开启高效的数据管理与备份体验。
