## ✨ 주요 기능

- 🚀 **간편한 설정**: 원격 서비스 설정을 입력하기만 하면 바로 사용 가능.
- 📗 **실시간 노트 관리**: 보관함 내 노트 생성, 수정, 삭제를 자동으로 감지 및 동기화.
- 🖼️ **첨부 파일 완전 지원**: 이미지, 오디오, 비디오 등 다양한 미디어 동기화.
- ⚙️ **설정 동기화**: 여러 기기 간에 플러그인 설정 및 테마 동기화.
- 🔄 **멀티플랫폼 지원**: Mac, Windows, Android, iOS 완벽 지원.
- 📝 **노트 기록**: 수정 기록 확인 및 이전 버전 복원 지원.
- ☁️ **첨부 파일 클라우드 미리보기**: 온디맨드 미리보기를 통해 로컬 저장 공간 절약.

## 🚀 빠른 시작

1. **BRAT을 통한 설치**: Obsidian 커뮤니티 플러그인 BRAT을 열고 `zoudeying/obsidian-quick-data-management`를 추가합니다.
2. **수동 설치**: [GitHub Releases](https://github.com/zoudeying/obsidian-quick-data-management/releases)에서 `main.js`, `styles.css`, `manifest.json`을 다운로드하여 `.obsidian/plugins/obsidian-quick-data-management` 폴더에 넣습니다.
3. Obsidian 설정 > **Quick Data Management**를 열고 연결 정보를 설정합니다.
