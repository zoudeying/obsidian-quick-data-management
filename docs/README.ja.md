## ✨ 主な機能

- 🚀 **シンプルな設定**: リモートサービス設定を入力するだけで即座に利用可能。
- 📗 **リアルタイムノート管理**: 保管庫内のノート作成、更新、削除を自動監視・同期。
- 🖼️ **添付ファイル完全サポート**: 画像、音声、動画などのメディアを同期。
- ⚙️ **設定の同期**: 複数デバイス間でプラグイン設定やテーマを同期。
- 🔄 **マルチプラットフォーム対応**: Mac、Windows、Android、iOS を完全サポート。
- 📝 **ノート履歴**: 変更履歴の確認や過去バージョンへの復元に対応。
- ☁️ **添付ファイルクラウドプレビュー**: オンデマンドでプレビューし、ローカル容量を節約。

## 🚀 クイックスタート

1. **BRAT によるインストール**: Obsidian のコミュニティプラグイン BRAT を開き、`zoudeying/obsidian-quick-data-management` を追加します。
2. **手動インストール**: [GitHub Releases](https://github.com/zoudeying/obsidian-quick-data-management/releases) から `main.js`, `styles.css`, `manifest.json` をダウンロードし、`.obsidian/plugins/obsidian-quick-data-management` に配置します。
3. Obsidian の設定 > **Quick Data Management** を開き、接続設定を行います。
